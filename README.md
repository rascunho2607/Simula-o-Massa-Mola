# Simulação de Tecido Interativa com Sistema de Upgrades

Uma simulação física de tecido baseada em massa-mola com sistema completo de upgrades e habilidades especiais.

## 🎮 Funcionalidades Principais

### 🕸️ Simulação Física
- **Malha dinâmica** com sistema massa-mola realista
- **Gravidade ajustável** e física de Verlet
- **Rasgar tecido** ao arrastar rapidamente com o botão direito
- **Pontos fixáveis** com dardos para criar âncoras

### 🔧 Ferramentas Interativas
- **🖱️ Mouse** - Arraste para interagir diretamente
- **💨 Soprador** - Empurra/puxa o tecido (modo sopro/sucção)
- **🎯 Canhão** - Atira bolas que interagem com a malha
- **📍 Dardos** - Prendem pontos específicos do tecido
- **🔥 Lança-Chamas** - Incendeia e queima o tecido

### ⚡ Sistema de Progressão
- **Níveis e XP** - Ganhe experiência interagindo
- **Pontos de Upgrade** - Desbloqueie melhorias
- **Barra de XP** - Acompanhe seu progresso
- **Evolução contínua** - Suba de nível para mais recursos

### 🛠️ Sistema de Upgrades
**Para cada ferramenta:**
- **Força** - Aumenta intensidade do efeito
- **Alcance** - Expande área de influência
- **Eficiência** - Reduz custo em recursos

### ✨ Habilidades Especiais
**Canhão:**
- Ricochete, Explosão, Fragmentação, Teleguiado, Fogo Rápido

**Dardos:**
- Explosão Retardada, Corrente Elétrica, Multi-Dardo, Ímã, Portal

**Soprador:**
- Vórtice, Congelante, Repulsor, Sucção, Tornado

**Fogo:**
- Propagação, Chamas Coloridas, Faíscas, Anel de Fogo, Fênix

**Mouse:**
- Teia, Campo de Força, Gosma, Ímã Seletivo, Duplicação

## 🎯 Controles

### Teclas de Ferramentas:
- **M** - Mouse
- **B** - Soprador
- **C** - Canhão
- **D** - Dardos
- **L** - Lança-Chamas

### Teclas de Ação:
- **R** - Remover todos os dardos
- **F** - Apagar todo o fogo
- **Espaço** - Disparar (Canhão/Dardos) ou Ativar Fogo
- **Q/E/R/T/Y** - Ativar habilidades especiais (quando disponíveis)

### Interface:
- **⚙️** - Configurações da simulação
- **⚡** - Menu de upgrades
- **★** - Habilidades especiais

## 🎮 Como Jogar

1. **Comece a interagir** - Arraste o mouse para manipular o tecido
2. **Ganhe XP** - Cada interação física concede experiência
3. **Suba de nível** - Atinja novos níveis para ganhar pontos de upgrade
4. **Aprimore ferramentas** - Use pontos para melhorar força, alcance e eficiência
5. **Desbloqueie habilidades** - Invista em habilidades especiais únicas
6. **Experimente combinações** - Combine ferramentas e habilidades para efeitos surpreendentes

## ⚙️ Configurações

Ajuste diversos parâmetros da simulação:
- Número de linhas e espaçamento
- Rigidez das molas e gravidade
- Atrito e distância para rasgar
- Intensidade do fogo e cores da malha

## 💾 Salvamento Automático

O progresso é salvo automaticamente no navegador:
- Nível e XP
- Upgrades adquiridos
- Habilidades desbloqueadas
- Configurações personalizadas

## 📱 Responsividade

Interface adaptada para diferentes tamanhos de tela:
- Layout otimizado para desktop e mobile
- Elementos de UI reposicionáveis
- Ferramentas acessíveis em qualquer resolução

## 🚀 Tecnologias

- **HTML5 Canvas** - Renderização da simulação física
- **JavaScript Vanilla** - Lógica completa sem dependências
- **CSS3** - Interface moderna e responsiva
- **Local Storage** - Sistema de salvamento

## 🎨 Recursos Visuais

- **Partículas dinâmicas** para efeitos especiais

- Ajuste parâmetros físicos em tempo real
